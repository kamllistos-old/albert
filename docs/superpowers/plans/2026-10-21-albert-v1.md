# Albert v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `albert`, a Go binary for macOS that lists, updates and installs tools from 12 package-manager sources through a CLI and through a web GUI served from a Docker container (or natively as a fallback).

**Architecture:** One Go binary holds the providers (one per package manager), an inventory/cache, a job runner, an fsnotify watcher, and an HTTP agent bound to 127.0.0.1. `albert up` starts the agent as a detached process and a Caddy container (`albert-ui`) that serves the static UI and reverse-proxies `/api` to the agent via `host.docker.internal`. CLI commands other than `up`/`down`/`status` call providers directly.

**Tech Stack:** Go 1.26 (stdlib + `github.com/fsnotify/fsnotify`), plain JavaScript ES modules + CSS (no build step), Caddy 2 on Alpine, goreleaser, GitHub Actions, GHCR.

**Spec:** `docs/superpowers/specs/2026-10-21-albert-design.md`

## Global Constraints

- Module path: `github.com/kamllistos/albert`. Binary name: `albert`. Container name: `albert-ui`. Image: `ghcr.io/kamllistos/albert-ui:<version>`.
- macOS only (darwin arm64 + amd64). No Linux/Windows code paths.
- Only external Go dependency: `github.com/fsnotify/fsnotify`. CLI uses stdlib `flag`.
- Agent binds `127.0.0.1` only. Default agent port 7878, default UI port 7879; next free port if busy.
- Every `/api` request needs a valid token (`Authorization: Bearer <token>` or cookie `albert_token`). `Host` must be in the allowed set; `Origin`, if present, must be `http://localhost:<ui port>` or `http://127.0.0.1:<ui port>`; every `POST` must carry `X-Albert-Request: 1`. No CORS headers, ever. (The agent enforces all of this; Caddy only proxies and preserves `Host`/`Origin`, so it needs no checks of its own.)
- Token: 32 random bytes, hex. Passed to the agent via a 0600 file, never as a CLI argument.
- State dir: `$ALBERT_HOME`, else `~/.albert`. Files: `state.json`, `cache.json`, `token`, `albert.log`.
- Timeouts: list 30s per provider, outdated 120s per provider, search 10s per provider. Watcher debounce 2s. Periodic outdated check every 6h while the agent runs.
- Registry lookups run at most 8 at a time per provider.
- pip: tools are `ReadOnly` unless installed with `--user`. "Update all" skips pip unless `includePip` / `--include-pip` is set.
- User-facing messages are written in plain English for non-technical users. Exact copy:
  - Docker down: `Docker isn't running. Open Docker Desktop, or press Enter to open Albert without it.`
  - Sudo needed: `This needs your password. Run "albert update <tool>" in Terminal.`
  - `albert down` with nothing running: `Albert isn't running.`
  - `albert down` success: `Albert stopped.`
- Tests never run real installs/upgrades and never touch the network: commands go through `runner.Fake`, registries through `httptest`.

## Review Focus

1. **First-ever scan:** with no cache file, nothing is marked `New`; only tools that appear in later scans are. Test: `TestFirstScanMarksNothingNew` (Task 7).
2. **Watcher-triggered rescan:** rescanning a provider after a filesystem change keeps the `Latest`/`Outdated` values from the last outdated check. Test: `TestRescanKeepsLatest` (Task 7).
3. **Manager installed but broken** (e.g. this machine's `pnpm`, which exits non-zero with `The configured global bin directory ... is not in PATH`): the provider shows as unavailable with the first stderr line as the reason, and other providers still list. Test: `TestPnpmListErrorSurfacesReason` (Task 5) and `TestFailingProviderIsolated` (Task 7).
4. **Hostile tool names from the install box or CLI** (`--force`, `-rf`, `a b`, `x;rm`): rejected before any command runs. Test: `TestValidName` (Task 2), `TestInstallRejectsBadName` (Task 10).
5. **Stale state after reboot or crash** (state.json points at a dead or reused PID): `albert up`/`status` decide "running" from an authenticated `/api/health` call, not from the PID alone, so a stale file never blocks startup. Test: `TestIsRunningStalePID` (Task 13).

### Task 7: Inventory + cache

**Files:**
- Create: `internal/inventory/inventory.go`
- Test: `internal/inventory/inventory_test.go`

**Interfaces:**
- Consumes: `provider.Provider`, `provider.Tool`, `provider.Update`.
- Produces:
```go
package inventory
var ListTimeout, OutdatedTimeout = 30 * time.Second, 120 * time.Second
type ProviderStatus struct { Name string; Available bool; Error string; Checking bool; LastScan time.Time } // lowerCamel json
type Snapshot struct { Tools []provider.Tool; Providers []ProviderStatus; CheckingUpdates bool }
func New(ps []provider.Provider, cachePath string) *Inventory // cachePath "" = no persistence
func (i *Inventory) ScanAll(ctx context.Context)              // parallel List of available providers
func (i *Inventory) Scan(ctx context.Context, source string) error
func (i *Inventory) CheckOutdated(ctx context.Context, source string) // "" = all available, parallel
func (i *Inventory) Snapshot() Snapshot                        // tools sorted by Source, then Name
func (i *Inventory) Provider(name string) (provider.Provider, bool)
func (i *Inventory) Subscribe() (<-chan struct{}, func())      // buffered(1), non-blocking notify on any change
```
Rules:
- Each List/Outdated call gets its own timeout; errors/timeouts set `ProviderStatus.Error` and leave that provider's tools empty; other providers unaffected.
- Latest values from the last `CheckOutdated` are stored per source and reapplied after every `Scan`. `Outdated = Latest != "" && Latest != Version`. Update Description/Homepage fill Tool fields only when empty.
- Cache file JSON: `{"firstSeen": {"<source>/<name>": "<RFC3339>"}, "latest": {"<source>": {"<name>": "<ver>"}}}`. On load, `latest` restores badges. If the cache file did not exist, every tool found by the first `ScanAll` is recorded with zero time. `New = !firstSeen.IsZero() && time.Since(firstSeen) < 24h`.
- `CheckingUpdates` true while any CheckOutdated runs; `ProviderStatus.Checking` per provider.

  - `TestScanAllParallelAndSorted`
  - `TestFailingProviderIsolated` (one returns error → its status Error set, other's tools present)
  - `TestListTimeoutIsolated` (set `ListTimeout=50ms`; slow provider sleeps 1s; ScanAll returns in <500ms)
  - `TestFirstScanMarksNothingNew` (no cache file → no tool `New`)
  - `TestLaterToolMarkedNew` (scan, add tool, Scan(source) → only it is `New`; reload from cache → still `New`)
  - `TestRescanKeepsLatest` (CheckOutdated sets Latest; Scan again → `Outdated` still true)

Hidden command: `albert agent --port P --ui-port U --mode docker|native` → reads token from `<dir>/token`, calls `agent.Run`.

`up` sequence:
1. `isRunning` → print `Albert is already running at http://localhost:<ui>`, open URL, exit 0. Stale state → `Clear` and continue.
2. Mode: `--native` → native. Else `docker.Ready` fails → if tty print the Docker-down message and wait for Enter (then native); if not tty go native and print `Docker isn't running — opening Albert without it.`
3. `agentPort = FreePort(7878)`; `uiPort` = `FreePort(7879)` in docker mode, `agentPort` in native mode; `WriteToken`.
4. `spawn(["agent","--port",…,"--ui-port",…,"--mode",…])`; poll `health` every 200ms up to 10s; timeout → kill, Clear, print `Albert couldn't start. Details: <dir>/albert.log`, exit 1.
5. Docker mode: `EnsureImage(dock.Image(version), albert.Files)` (print `Preparing Albert's window (first time only)…` if not present) then `Start`; failure → kill agent, Clear, print error, exit 1.
6. `Save` state, print `Albert is running at http://localhost:<ui>` and `Stop it any time with: albert down`, `openURL` unless `--no-open`.

`down`: load state; if docker mode or no state → `docker.Stop` (errors ignored); if PID set → `kill`; `Clear`; print `Albert stopped.` — or `Albert isn't running.` when there was no state and nothing to stop.

`status`: running → `Running at http://localhost:<ui> (mode: docker, since 15:04)`; else `Albert isn't running. Start it with: albert up`.
